# ApexGrid Motorsport Career Platform — Brand & Design System

## Summary

This directory contains the independent internal design system for the ApexGrid Motorsport Career Platform. It documents the product's visual identity, personas, interaction model, content language, accessibility rules and implementation standards.

## Files

- `design-system.html` — documentation and live component playground
- `design-system.css` — system tokens, responsive rules and component styles
- `design-system.js` — navigation, search, tabs, modal, copy and interaction behavior

## Run

Open `design-system.html` directly in a browser, or serve the folder with any static server.

## Design direction

- Primary: `#F32F3F`
- Secondary: `#D5AD43`
- Background: `#0C0F12`
- Surface: `#12171C`
- Text: `#F5F6F8`
- Muted text: `#9AA3AD`

The implementation is intentionally independent from the product web application so that the system can be reviewed, maintained and extended without coupling to the current page implementation.
